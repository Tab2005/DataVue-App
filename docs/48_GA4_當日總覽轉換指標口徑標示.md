# 48_GA4 當日總覽轉換指標口徑標示

## 背景

使用者發現「當日總覽」儀表板的「轉換」卡片數字，可能包含加入購物車事件，詢問是否可以拆開或選擇。

## 釐清

「轉換」用的是 GA4 官方 `conversions` 指標（`backend/modules/ga4/insights/_shared.py::DASHBOARD_METRICS`），這個指標的定義是「該 GA4 屬性裡，所有被標記為關鍵事件（Key Events）的事件次數總和」——**是否包含加入購物車，取決於使用者自己在 GA4 後台（管理 → 事件 → 標示為關鍵事件）怎麼設定，不是本系統決定的**。若該屬性把 `add_to_cart` 也標成關鍵事件，這裡的數字就會把加購跟購買混在一起算。

到達頁分頁已經有更細的拆分能力（`key_event` 參數 + `available_key_events` 下拉，可選「全部關鍵事件」或單獨看某一個事件），但「當日總覽」目前沒有類似的拆分/選擇功能，純粹是加總。

## 本次處理範圍

使用者要求先在畫面上標示清楚，避免誤以為都是購買轉換，暫不做拆分/選擇功能（留待之後有需要再規劃）。

- `frontend/src/components/GA4Insights/GA4InsightsShared.jsx::IntradayMetricCard`：`metricKey === 'conversions'` 時，卡片標題旁加一個 ⓘ 提示，說明「此為 GA4 關鍵事件總和，可能包含加入購物車、註冊等，不一定只是購買轉換」

## 不在本次範圍內

- 「當日總覽」比照到達頁分頁做關鍵事件拆分/選擇（例如只看 `purchase`）——之後有需要再另外規劃實作
